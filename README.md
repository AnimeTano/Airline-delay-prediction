# Airline Delay Prediction

## Цель проекта

Спрогнозировать, будет ли **месяц проблемным** для конкретной авиакомпании в конкретном аэропорту.

**Проблемный месяц** – это месяц, в котором доля задержанных рейсов (`arr_del15 / arr_flights`) превышает **20%**.

Это помогает авиакомпаниям:
- заранее выявлять рискованные периоды;
- планировать резервные борта и экипажи;
- снижать операционные риски и компенсационные выплаты.

---

## Данные

- **Источник:** [Airline Delay Dataset (Kaggle)](https://www.kaggle.com/datasets/sriharshaeedala/airline-delay)
- **Период:** 2013–2023
- **Формат:** агрегированные данные по месяцам, авиакомпаниям и аэропортам.
- **Размер:** ~171k строк, 21 колонка.

---

## Задача

**Бинарная классификация**  
Целевая переменная: `bad_month` (0 – нормальный, 1 – проблемный)

---

## EDA (краткие выводы)

- Наиболее проблемные месяцы: **июнь, июль, декабрь**.
- Наименее проблемные: **сентябрь, октябрь, ноябрь**.
- Есть сильная сезонность и влияние года (пик в 2014 и 2023, провал в 2020).
- Загруженность аэропорта положительно коррелирует с вероятностью проблем.
- Основные причины задержек в проблемные месяцы: **поздний прилёт ВС**, **проблемы NAS**, **задержки авиакомпании**.
- Числовые признаки слабо коррелируют с `bad_month`, ключевую роль играют **категориальные** (авиакомпания, аэропорт).

Подробный EDA – в [01_eda.md](01_eda.md).

---

## Feature Engineering

- Удалены прямые утечки (признаки задержек за тот же месяц);
- Добавлены циклические признаки для месяца (`sin`, `cos`);
- Добавлена категория сезона;
- Целевое кодирование для `carrier` и `airport` (с кросс-валидацией);
- Масштабирование числовых признаков;

---

## Моделирование

Использованы модели:
- Logistic Regression (baseline)
- Gradient Boosting
- Random Forest
- XGBoost

**Метрика:** ROC-AUC (основная) + Precision/Recall/F1.
